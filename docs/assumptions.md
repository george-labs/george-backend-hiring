# Assumptions per iteration

## Iteration 4

- Assumed is that only stretches of letters (a-z,A-Z) are counted as words. Example: "Humpty-Dumpty" or "wall." are not words.

## Iteration 5

- Assumed is that a word containting the hypen character is a valid word only if the word doesn't start nor end with the hypen character.

## Iteration 6

- Assumed format for the output of average word length is 2 decimal spots.
